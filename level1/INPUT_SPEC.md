# 定时自动浇花控制器：Level 1 输入规格（草案）

这份文件说明希望控制器件完成什么功能，是交给 Level 1 设计或器件选型的**输入需求**，不是已经制造出的芯片，也不是器件数据手册。当前产品按固定间隔浇水，**不使用土壤湿度传感器**。早期的 `pump_gate.v` 只用于学习组合逻辑，不实现本规格。

## 1. 产品行为

- 每经过用户设定的固定间隔 `T`，产生一次浇水机会；默认 **24 小时**。用户可修改 `T`，不需要保存每天的真实钟点。允许的设置范围和调节步长待确定。
- 到点时若水箱有水且没有报告故障，请求启动水泵。单次运行时长由用户设置，默认 **40 秒**；达到设定时长后停泵。
- 用户可以取消**本次**浇水：若水泵正在运行，立即停泵；若本次尚未开始，跳过下一次到点的浇水。之后的浇水机会照原间隔继续，不进入永久暂停模式。
- 运行途中发现缺水或故障，立即停泵。本次不会自动重新启动，等待下一次到点。
- 上电和复位期间，水泵保持关闭。第一次浇水机会暂按上电后经过完整间隔 `T` 计算；断电后是否保留计时进度待确定。

这里的“本次”指当前或下一次到点的浇水机会。取消一次不会改变后续的到点节奏。

## 2. 控制器边界与信号

| 项目 | 方向 | 含义 |
| --- | --- | --- |
| `clk` | 输入 | 控制器时钟；频率随实际器件确定 |
| `reset` | 输入 | 使控制器回到停泵状态；有效电平随实际器件确定 |
| `water_ok` | 输入 | `1` 表示水箱有水，`0` 表示缺水 |
| `fault` | 输入 | `1` 表示外部系统报告故障，`0` 表示未报告故障 |
| `cancel_once` | 输入 | 用户发出一次取消命令；按键去抖和有效电平待接口设计确定 |
| `T`、`run_duration` | 配置 | 用户可分别设置固定浇水间隔和单次运行时长；默认值分别为 24 小时、40 秒 |
| `pump_req` | 输出 | `1` 请求水泵驱动器运行，`0` 请求关闭 |

定时器产生的“本次运行中”是控制器的**内部状态**，不是土壤传感器输入。输出必须同时满足“正在本次运行中、水箱有水、无故障、没有取消本次”。完整控制器需要用时钟和状态记录“是否到点”“已运行多久”“本次是否跳过”；单个组合逻辑表达式不能完成定时。

`fault` 的检测来源尚待系统方案定义，不能假设控制器会自行诊断所有故障。若最后选择现成微控制器，定时、取消和运行时长逻辑可由 Level 3 固件实现；若选择专用数字芯片，这些状态机和计数逻辑属于 Level 1。两种实现都必须满足上述产品行为。

## 3. 安全和验证要求

| 场景 | 期望的 `pump_req` |
| --- | --- |
| 上电、复位或尚未到下一次浇水时间 | `0` |
| 到点，水箱有水、无故障、本次未被取消 | `1`，最多持续用户设定时长 |
| 运行达到设定时长 | `0` |
| 当前或下一次浇水被用户取消 | `0`；后续间隔仍正常计时 |
| 缺水或报告故障，包括运行中发生 | `0`；本次不自动重启 |

后续验证至少覆盖到点、计时结束、上电与复位、运行中取消、提前取消、运行中缺水与故障，以及恢复后的下一次到点。

## 4. 交给 Level 2 的实际器件资料

Level 1 的**可用输出**是选定的真实控制器件或已完成的专用芯片资料：型号、数据手册、供电范围、输入电平门限、输出驱动能力、上电行为、引脚定义、封装和推荐焊盘。仅有 RTL、仿真结果或逻辑网表，不能直接画出可制造的 PCB。

Level 2 还需确定实际水泵的供电、额定与启动电流、水位检测方式、用户取消按钮、固定间隔与运行时长的设置接口。现阶段暂以标称 3.3 V 控制逻辑和 5 V 水泵作为待核对的设计起点；控制器的 `pump_req` 只接水泵驱动电路，不能直接给水泵供电。
